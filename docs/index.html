galeri-live

Lihat isi galeri HP dengan tampilan scroll seperti TikTok. Video langsung terputar, foto tampil layar penuh.

Aplikasi ini hanya untuk Android. Buka halaman ini di HP Android Anda.

Cara memasang

  1. Ketuk Unduh APK, tunggu sampai selesai.
  2. Buka file yang terunduh. Jika diminta, izinkan pasang dari sumber ini.
  3. Ketuk Pasang. Jika muncul peringatan Play Protect, pilih Tetap instal.
  4. Buka galeri-live lalu ketuk Izinkan untuk akses foto dan video.

Memperbarui aplikasi

  1. Buka aplikasi, ketuk ikon cari atau tombol Galeri.
  2. Jika ada versi baru, ketuk Update, lalu Pasang. Tidak perlu kembali ke halaman ini.

File di HP Anda hanya dibaca, tidak diubah, dihapus, atau diunggah ke mana pun.
